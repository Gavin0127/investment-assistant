# 利润跟踪 Dashboard 重设计

## 目标

将利润跟踪 Dashboard 从卡片网格布局改为页签 + 左右分栏布局，支持在线编辑模型参数并即时预览利润曲线变化。

## 当前状态

- 每个股票一个卡片，纵向排列（`grid-cols-1 lg:grid-cols-2`）
- 卡片内容：ECharts 图表 + 三场景汇总表
- 模型参数完全隐藏，编辑需要跳转到股票详情页

## 设计方案

### 布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│ 利润跟踪                                        [刷新价格数据] │
├─────────────────────────────────────────────────────────────────┤
│ [中国海油]  [云铝股份]  [紫金矿业]  ← 页签，动态从 API 获取    │
├─────────────────────────────────┬───────────────────────────────┤
│                                 │ 模型参数                      │
│                                 │                               │
│     ECharts 双线图              │ 年化方式  [H1x2 ▼]           │
│     (~65% 宽度)                 │ 基准期间  [2026H1    ]        │
│                                 │ 基准利润  [1200      ] 亿元   │
│                                 │ 基准价格  [72.5      ] USD    │
│                                 │ 敏感系数  [15.2      ]        │
│                                 │                               │
│                                 │ 原材料 (只读)                 │
│                                 │ ● Brent原油  BZ=F  yfinance  │
│                                 │                               │
│                                 │ [保存]  [重置]                │
├─────────────────────────────────┴───────────────────────────────┤
│ 场景        │ 利润         │ 价格窗口          │ 原材料价格     │
│ 最新价格    │ 1506.89 亿元 │ 03-06 至 03-06    │ BZ=F: 92.69   │
│ 最近1个月   │ 1212.71 亿元 │ 02-06 至 03-06    │ BZ=F: 73.34   │
│ 年初至今    │ 1145.66 亿元 │ 01-02 至 03-06    │ BZ=F: 68.92   │
└─────────────────────────────────────────────────────────────────┘
```

### 页签交互

- 页签列表从 `/api/profit/models` 动态获取
- 当前选中页签高亮（蓝色底色 + 下边框）
- 切换页签时加载对应股票的价格数据和模型参数
- 空状态：无模型时显示引导文案

### 参数面板

可编辑字段：
- `annualization`：下拉选择（H1x2 / Qx4 / annual）
- `base_period`：文本输入
- `base_profit`：数字输入
- `base_commodity_price`：数字输入
- `sensitivity`：数字输入

只读展示：
- `commodities` 列表（名称、symbol、source）

按钮：
- "保存"：POST `/api/profit/<stock_id>/model` 持久化参数
- "重置"：恢复到上次保存的值

### 前端即时重算

```
用户修改参数
    ↓
前端用已有 daily 价格数据 + 新参数即时重算
    ↓
图表 + 三场景表格实时更新（无后端请求）
    ↓
用户点击 [保存]
    ↓
POST /api/profit/<stock_id>/model 持久化
```

重算公式（单原材料）：
```
period_profit = base_profit + (price - base_price) × sensitivity
annualized_profit = period_profit × multiplier
```

multiplier 映射：`{ H1x2: 2, Qx4: 4, annual: 1 }`

多原材料时，对每个 commodity 分别计算 period_profit 再求和后乘 multiplier。

三场景重算：
- 最新价格：取 daily 最后一天的 commodity_prices
- 最近1个月均价：取最近一个自然月的 daily 数据求均价
- 年初至今均价：取全部 daily 数据求均价

### 状态管理

```javascript
{
  activeTab: 'cnooc',           // 当前选中的页签
  models: [],                    // 所有模型列表
  rawDaily: {},                  // 原始价格数据 { stockId: daily[] }
  editParams: {},                // 编辑中的参数 { stockId: {...} }
  savedParams: {},               // 上次保存的参数 { stockId: {...} }
  dirty: false,                  // 参数是否有未保存的变更
}
```

## 改动范围

仅修改 `web/templates/profit_dashboard.html`，不需要改后端。

## 不做的事

- 不支持 commodities 的增删改（在股票详情页操作）
- 不支持新建模型（在股票详情页操作）
- 不做响应式移动端适配（桌面端优先）
